# Example components

Hand-written, game-specific team pages and matchup cards kept as reference
for building year configs. The app renders the configurable versions
(`src/components/team-pages/configurable-team-page.tsx` and
`src/components/matchup/configurable-matchup-card.tsx`) instead; nothing
imports these files.

They are still type-checked and linted, so they stay in sync with the
components and hooks they import.
